## 👋 About Me

I'm a **Full Stack Team Lead** and Software Architect with 8+ years building production systems that solve real problems at scale. I've shipped platforms used by Meghalaya Government, Indian NGOs, and enterprises — from tracking 1,500+ rural entrepreneurs in the field to offline-first mobile apps that work without any internet connection.

My work spans the full stack: cloud infrastructure on **AWS**, data pipelines via **Airbyte**, **Flutter** mobile apps with offline sync, **AI/RAG** systems over large document corpora, and enterprise platforms on **Frappe/ERPNext**. I'm as comfortable designing a Kubernetes cluster as writing the React component that renders the data it serves.

- 🏗️ Currently building: offline-first field apps for social impact
- 🌍 Open source: [Frappe Mobile SDK](https://pub.dev/packages/frappe_mobile_sdk) · 5 Frappe apps · 2 Airbyte connectors
- 🎯 Focus areas: Cloud Architecture · Data Engineering · Mobile (Flutter) · AI/GenAI
- ✅ Frappe Certified Professional

## 🚀 Featured: Frappe Mobile SDK

> **The biggest contribution I'm proud of.**

An **offline-first Flutter SDK** that brings Frappe/ERPNext to mobile devices even without internet — built for field workers in rural India with low or no connectivity.

[![pub.dev version](https://img.shields.io/pub/v/frappe_mobile_sdk?style=flat-square&label=pub.dev&color=0175C2&logo=dart)](https://pub.dev/packages/frappe_mobile_sdk)
